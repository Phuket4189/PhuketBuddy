# PhuketBuddy · 桌面气泡 设计稿 v1.0

> 一句话：一个常驻桌面的小气泡，显示 PhuketAI 余额；点开是「余额 / 用量 / API Key」仪表盘。
> 配套：视觉原型的可交互版本见 [`design/prototype.html`](../design/prototype.html)（浏览器直接打开，可拖动、可吸边、可切换状态）。
> 前置结论见 [`01-可行性验证报告.md`](./01-可行性验证报告.md)。

---

## 1. 设计目标与约束

| 目标 | 量化标准 |
|---|---|
| 体积小 | 可执行文件 **≤ 8 MB**，安装包 ≤ 5 MB，无第三方运行时安装 |
| 不打扰 | 默认 64×64 气泡、无标题栏、不占任务栏；闲置 CPU < 0.3%、内存 < 120 MB |
| 吸边 | 距屏幕边缘 ≤ 24px 自动吸附，保留 8px 可见；多显示器 / 高 DPI 正确 |
| 一眼看清 | 不点开也能看到余额；点开后 1 屏内看到「余额 / 今日 / 趋势 / Key」 |
| 安全 | 密码不落盘；令牌 DPAPI 加密；只与本域通信 |
| 可降级 | 断网 / 接口变更 / 令牌失效时，软件不崩、不弹错误堆栈，而是给可操作提示 |

**明确不做**：不做代理转发、不做聊天客户端、不接管模型调用、不同步凭据到云端。

## 3. 技术选型

### 3.1 候选矩阵（体积为本机实测/官方基准）

| 方案 | 产物 | 内存 | 透明窗 | 托盘/吸边 | 本机工具链 | 判断 |
|---|---|---|---|---|---|---|
| Electron | ≥ 100 MB | 150 MB+ | ✅ | ✅ | 有 Node | ❌ 体积不符 |
| Flutter Win | 25–40 MB | 80 MB+ | ⚠️ 有限 | 需插件 | 已装 | ❌ 体积偏大 |
| .NET WPF（框架依赖） | **0.2–0.5 MB** | 40–60 MB | ✅ 原生最佳 | 手写 Win32 | 已装 .NET 10/8/9 | ⚠️ 需目标机装运行时 |
| .NET WPF（自包含） | **≈ 66 MB**（实测 57.8 MB exe + 8 MB 原生库） | 40–60 MB | ✅ | 手写 | 已装 | ❌ 体积不符 |
| Go + go-webview2 | **3.09 MB**（本机实测，裸壳） | 80–110 MB | ⚠️ 需手写 Win32 | 手写 Win32 | Go 1.27 已装 + WebView2 152 | ✅ 最省事的"小" |
| Go + Wails v2 | ≈ 10–14 MB | 90–120 MB | ✅ 内置 | 内置托盘/拖拽区 | Go + Node 已装 | ✅ 零新工具链 |
| **Tauri 2** | **≈ 3–6 MB** | 70–100 MB | ✅ 原生支持 | 官方插件 | 需装 Rust（MSVC 14.44 已在） | ✅ **推荐** |
| Win32 C++ | ≈ 0.3 MB | 15 MB | ✅ | 手写 | 有 MSVC，无 IDE 工程 | ❌ 成本过高 |

> 本机实测记录：
> - `dotnet publish -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true` → **57.8 MB** 单文件；框架依赖版仅 0.2 MB，但要求目标机存在 .NET Desktop Runtime。
> - `go build -ldflags "-s -w -H=windowsgui"`（go-webview2 裸壳）→ **3.09 MB**，零运行时依赖（WebView2 随系统）。

### 3.2 决策：Tauri 2

理由，按权重排序：

1. **体积**：3–6 MB 便携 exe，不依赖 .NET/VC 运行时；WebView2 在 Win10 1803+ / Win11 属系统级常驻组件（本机已装 152）。
2. **窗体能力**：`transparent + decorations(false) + alwaysOnTop + skipTaskbar` 一等公民；`tauri-plugin-autostart / single-instance / notification / updater` 现成。
3. **复用**：界面即 HTML/CSS，**本设计稿的原型可直接演进为成品 UI**，改版成本最低。
4. **跨域问题天然消失**：HTTP 走 Rust 侧 `reqwest`，不受浏览器 CORS 约束（站点 `OPTIONS` 实测 403，前端 fetch 必挂）。
5. **工具链就绪**：MSVC 14.44 已安装，`static.rust-lang.org` 可达，`rustup` 安装约 3–5 分钟；Node/pnpm 已就绪。

**风险与对冲**：Rust 首次编译较慢（约 3–6 分钟）；透明窗口在部分核显/远程桌面下会出现黑底 —— 提供「不透明模式」开关兜底。

**备选（已在本机验证可编译）**：
- **Go + go-webview2**：裸壳 **3.09 MB** 实测，体积最优、零新工具链；缺点是无内建托盘/透明，需要用 `w.Window()` 拿 HWND 手写 Win32 处理（约 300 行）。
- **Go + Wails v2**：内建透明窗口、无边框、托盘与拖拽区，产物约 10–14 MB；不想装 Rust 又不想写 Win32 时选它。
- **WPF**：仅当确定目标机都有 .NET 桌面运行时（本机 8/9/10 都有）时选，原生透明效果最好、体积 0.2 MB。

## 4. 信息架构

```
PhuketBuddy.exe（单进程）
├─ 气泡窗（Bubble Window）        64×64 透明置顶窗口，常驻
│   └─ 点击 → 同窗口扩展为 面板形态（不新开窗口，避免焦点闪烁）
├─ 面板（Panel View）             336 × 自适应高度
│   ├─ 头部：品牌 / 同步时间 / 设置
│   ├─ 余额区：credits + 预计可用天数
│   ├─ 指标区：今日消耗 / 今日请求 / 本月消耗 / 近 7 日总量
│   ├─ 趋势图：近 7 日柱状
│   ├─ Key 区：前 3 个 Key（名称、掩码、额度、状态）
│   └─ 底栏：刷新 / 打开网站
├─ 登录视图（首次 / 令牌失效）
├─ 设置视图（托盘进入）
└─ 托盘图标（右键菜单）
```

**关键工程决策：单窗口形变，而不是"气泡窗口 + 弹窗"两窗口。**
理由：双窗口在 Windows 上会出现 z-order 抖动、Alt-Tab 残留、点击外部收起困难；单窗口把尺寸从 64×64 动画到 420×470，稳定且实现简单。

## 5. 视觉设计

### 5.1 设计语言

品牌取自站点 `phuketai-mark`：**炭黑 `#25292D` + 海青 `#18A7A0`**，向"深海/浮标"意象延伸——气泡即浮标，面板即水面下的仪表。

### 5.2 设计令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--teal` | `#18A7A0` | 主色 / 进度环 / 强调 |
| `--teal-hi` | `#2FD4C8` | 高光、可点击文字 |
| `--panel` | `rgba(18,24,31,.86)` | 面板底（叠加 26px 背景模糊） |
| `--line` | `rgba(255,255,255,.09)` | 1px 分隔线 |
| `--txt` / `--muted` / `--dim` | `#E8EFF5` / `#93A3B1` / `#6B7B8A` | 三级文字 |
| `--ok` / `--warn` / `--bad` | `#34D399` / `#F5A524` / `#F05A5A` | 状态色 |
| 圆角 | 气泡 50%；面板 20px；控件 8–10px | |
| 字体 | Segoe UI Variable → Microsoft YaHei UI | 中文优先 |
| 数字 | `tabular-nums` | 防止跳动 |
| 动效 | 展开 `180ms cubic-bezier(.2,.9,.25,1)`；吸边 `160ms` 弹簧；呼吸 `5.6s ease-in-out` | |

### 5.3 气泡：五个状态

| 状态 | 触发 | 表现 |
|---|---|---|
| **Idle** | 常态 | 68px 圆，外环 = 今日预算占比，中间余额数字 + `CREDITS`；5.6s 上下呼吸 4px；青色光晕 |
| **Hover** | 鼠标悬停 | 放大 1.06，光晕增强，0.15s |
| **Dragging** | 按住拖动 | 暂停呼吸，缩放 1.03，窗体贴光标 |
| **Snapped** | 松手距边 ≤ 24px | 吸附，保留 8px 可见；悬停滑出 28px 露出完整气泡 |
| **Alert** | 余额 < 阈值 | 环变琥珀、2.4s 脉冲、单位文字变暖色；同时弹一次 Windows 通知 |

另有 `Offline` 态（灰环 + 右上角 4px ⚠ 点）与 `Loading` 态（环转圈）。

### 5.4 面板

- 尺寸 336px 宽；高度随内容 430–470px；圆角 20；`backdrop-filter: blur(26px) saturate(140%)`。
- 层级：余额（31px 渐变字，视觉焦点）→ 四宫格指标（10px 标签 / 15px 数值）→ 趋势（46px 高柱状，今日高亮发光）→ Key 列表（行高 40，悬浮高亮）→ 底栏。
- 信息密度：**一屏不滚动**（Key 超过 3 条时显示"管理"跳转）。
- 定位：默认贴气泡所在侧；水平方向空间不足自动翻转；垂直方向 clamp 到工作区（已扣除任务栏）。

### 5.5 登录视图

336 × 340：品牌块 52px → 标题 → 邮箱/密码 → 安全说明（"DPAPI 加密，仅存本机"）→ 主按钮 → 注册链接。
错误提示内联在按钮上方，不弹模态框。

### 5.6 动效原则

- 只动 `opacity / transform`，不动布局属性。
- 所有展开/收起 ≤ 220ms；不做超过 300ms 的动画。
- 尊重系统"减少动画"设置。

## 6. 交互与窗体行为

### 6.1 吸边算法

```ts
const SNAP = 24;      // 吸附阈值（DIP）
const PEEK = 8;       // 吸附后保留可见像素
const EDGE_PAD = 4;   // 与屏幕边缘的间隙

// 用工作区而非整屏：多屏 + 任务栏高度都要扣掉
function onDragEnd(win, cursor, workArea) {
  const gaps = {
    left:   win.x - workArea.x,
    right:  workArea.x + workArea.w - (win.x + win.w),
    top:    win.y - workArea.y,
    bottom: workArea.y + workArea.h - (win.y + win.h),
  };
  const [edge, d] = minEntry(gaps);
  if (d > SNAP) return savePosition(win.x, win.y);      // 自由摆放

  const t = { edge, offset: cursor.offsetAlong(edge) };  // 记住沿边位置
  const target = snapRect(edge, t, workArea);
  animate(win, target, 160, spring);                      // 弹簧吸附
  win.hiddenPart = PEEK;                                  // 悬停时滑出
  saveEdgeAnchor(t, monitorId());                         // 多屏记忆
}
```

- **沿边位置记忆**：同一边缘再次吸附时，回到上次的沿边偏移量。
- **多屏**：按显示器 `workArea` 计算；分辨率/缩放变化时，把气泡收回主屏最近边缘。
- **半隐藏**：吸附后可选 1.5s 后自动半隐（仅留 8px）；鼠标进入时 140ms 滑出。
- **展开时避让**：吸附在右边缘时面板向左展开，左边缘反之；顶部/底部吸附时面板垂直翻转。

### 6.2 交互清单

| 操作 | 行为 |
|---|---|
| 单击气泡 | 展开面板（拖动位移 > 3px 视为拖拽，不触发） |
| 再点气泡 / 点空白 / `Esc` | 收起 |
| 拖动气泡 | 移动；松手吸边 |
| 双击气泡 | 立即刷新数据 |
| 右键气泡 | 与托盘相同的菜单（刷新 / 设置 / 隐藏 / 退出） |
| 托盘左键 | 显示/隐藏气泡 |
| 托盘右键 | 菜单：显示气泡、立即刷新、开机自启、设置、退出 |
| 滚轮悬停气泡（P1） | 切换显示的指标（余额 / 今日消耗 / 今日请求） |

### 6.3 边缘情况

- **展开时面板超出工作区**：先翻转，再 clamp，最后才允许滚动。
- **拖动时经过任务栏**：不吸附到任务栏区域（用 workArea）。
- **Win+D 显示桌面**：气泡保持置顶（`alwaysOnTop` + `skipTaskbar`）。
- **全屏应用**（游戏/放映）：自动隐藏气泡，退出全屏后恢复（`SetWinEventHook` 或轮询前台窗口）。
- **远程桌面/显卡异常**：自动切"不透明模式"（圆角矩形 + 实体背景）。

## 7. 系统架构

```
┌──────────────────────────── Tauri 2 进程 ────────────────────────────┐
│                                                                     │
│  WebView（HTML/CSS/TS）                Rust 主进程                    │
│  ┌───────────────────────┐            ┌────────────────────────────┐ │
│  │ BubbleView / PanelView│  invoke →  │ commands:                   │ │
│  │ LoginView / Settings  │ ← event    │  login / logout             │ │
│  │ store (内存缓存)       │            │  fetch_dashboard            │ │
│  └───────────────────────┘            │  fetch_trend / fetch_keys   │ │
│                                       │  set_window_mode (64↔470)   │ │
│                                       │  snap_window / tray_menu    │ │
│                                       └─────────────┬──────────────┘ │
│                                                     │ reqwest (HTTPS) │
│                                       ┌─────────────▼──────────────┐ │
│                                       │ ApiClient  令牌自动续期      │ │
│                                       │ SecureStore (DPAPI)         │ │
│                                       │ Scheduler  轮询/退避         │ │
│                                       └────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
                                    │
                        https://ai.pukitcore.com/api/v1
```

**分层**：View（无业务）→ Store（UI 状态）→ Command（Rust，唯一网络出口）→ ApiClient（鉴权/重试/解析）→ SecureStore（凭据）。

**线程模型**：网络在 tokio 任务；窗口操作用 `app.run_on_main_thread`；UI 只通过 `emit` 收事件。

**状态机**：

```
        ┌─────────┐  登录成功   ┌─────────┐  令牌失效  ┌──────────┐
        │  Login  │ ─────────→ │  Ready  │ ─────────→ │ Reauth   │
        └─────────┘             └────┬────┘            └────┬─────┘
              ↑                      │ 网络失败              │
              │                      ▼                      │
              │                 ┌─────────┐                 │
              └───── 退出登录 ── │ Offline │ ←─── 恢复 ──────┘
                                └─────────┘
```

## 8. 数据层

### 8.1 接口映射

| 界面数据 | 接口 | 频率 |
|---|---|---|
| 余额、昵称 | `GET /auth/me` | 气泡轮询 5 min |
| 今日/本月/请求数/Key 数 | `GET /usage/dashboard/stats` | 展开面板时 |
| 7 日柱状 | `GET /usage/dashboard/trend?start_date&end_date&granularity=day` | 展开面板时 |
| 模型分布（P1） | `GET /usage/dashboard/models` | 展开时（懒加载） |
| Key 列表 | `GET /keys` | 展开面板时 |
| 单 Key 日用量（P1） | `GET /user/api-keys/{id}/usage/daily?days=30` | 点击 Key 时 |
| 公告 | `GET /announcements` | 启动一次 |

### 8.2 同步策略

- **Stale-While-Revalidate**：启动先用本地缓存渲染（< 50ms 出图），后台再拉真实数据。
- **并发合并**：展开面板时并行请求 3 个接口，任一失败不影响其余区块渲染。
- **失败退避**：1 → 2 → 5 → 15 分钟，恢复后回到基础间隔。
- **写后刷新**：Key 的增删改成功后立即刷新 Key 区块与余额。

### 8.3 数据模型（TS）

```ts
interface User { id: number; email: string; balance: number;
                 balance_notify_enabled?: boolean; balance_notify_threshold?: number }

interface DashboardStats {
  today_requests: number; total_requests: number;
  today_actual_cost: number; total_actual_cost: number;
  total_api_keys: number;
  by_platform?: Array<{ platform: string; requests?: number; cost?: number }>;
}

interface ApiKey { id: number; name: string; key: string; quota: number;
                   status: string; expires_at?: string | null; group?: string }

interface TrendPoint { date: string; cost?: number; requests?: number; tokens?: number }
```

> 所有字段建议以 `?` 声明并在解析层归一化（数字字符串 → number、缺失 → 0），以抵御站点改版。

## 9. 安全与隐私

| 项 | 方案 |
|---|---|
| 密码 | **不落盘**，只在登录瞬间进内存；登录成功后立即丢弃 |
| 令牌 | DPAPI（`CryptProtectData`，绑当前 Windows 用户）加密存 `%APPDATA%\PhuketBuddy\session.bin` |
| 网络 | 仅 `https://ai.pukitcore.com`；证书校验开启；代理可配（P1） |
| 日志 | 默认关闭；开启时对 token/key 做 `sk-****` 脱敏 |
| 截屏/剪贴板 | 不读取 |
| 退出 | 提供"退出并清除登录"，删除 session 与缓存 |
| 更新 | P2；启用时校验签名 |

**合规边界**：本软件是"个人账号的只读仪表盘 + 少量自助管理"，不代理模型请求、不共享凭据、不做多租户，不触碰站点条款红线。

| M3 打磨 | 多屏/DPI、异常态、通知、托盘菜单、自启 | v0.9 | 0.5 d |

**验收清单**：① exe ≤ 8MB；② 冷启动 ≤ 1.2s；③ 四个边缘吸边 + 双屏正确；④ 断网不崩且提示可操作；⑤ 令牌过期自动续期；⑥ 连续运行 24h 内存增长 < 10MB；⑦ 退出后无残留进程。

## 13. 风险与备选

| 风险 | 影响 | 对冲 |
|---|---|---|
| 站点接口改版 | 面板空白 | 防御式解析 + 版本探测 + 失败降级"打开网页" |
| WebView2 缺失/损坏 | 无法启动 | 启动自检，引导安装 WebView2 Runtime（≈2MB 在线安装器） |
| 透明窗在部分机器黑底 | 观感差 | 设置里一键切"不透明模式" |
| Rust 编译环境 | 拖慢开发 | 已确认 MSVC + rustup 可达；备选 Go+WebView2 方案可 1 天内切换 |
| 风控误判 | 登录失败 | 固定 UA、低频、指数退避；必要时引导用户网页登录后粘贴令牌（**兜底方案**） |
