# PhuketBuddy 源码包

解压后即为完整工程，构建方式见 README.md 的「从源码构建」。

## 目录

```
PhuketBuddy-src/
├── README.md            使用与构建说明
├── build.ps1            一键构建脚本
├── ui/                  前端（纯 HTML/CSS/JS，被打包进 exe）
│   ├── index.html       气泡窗口
│   └── panel.html       面板（登录 / 仪表盘 / 设置）
├── src-tauri/           Tauri 2 + Rust 主程序
│   ├── Cargo.toml / Cargo.lock
│   ├── build.rs
│   ├── tauri.conf.json
│   ├── capabilities/    权限
│   ├── icons/           图标
│   └── src/
│       ├── main.rs      入口（WebView2 参数）
│       ├── lib.rs       状态机、命令、托盘、窗口
│       ├── api.rs       HTTP 客户端 + 容错解析
│       ├── secure.rs    DPAPI、数据目录回退、自启
│       └── win.rs       工作区/吸边/面板定位
├── preview/             界面截图
└── docs/                可行性报告、设计稿、交互原型
```

## 构建前置

- Windows 10 1803+ / 11
- Rust 稳定版（MSVC 工具链）+ Visual Studio Build Tools
- WebView2 Runtime（Win10/11 一般已内置）
- 无需 Node.js（前端是纯静态文件）

```powershell
cd src-tauri
cargo build --release
# 产物：src-tauri/target/release/phuketbuddy.exe
```

或直接运行 `build.ps1`（脚本里写死了本机路径，按需修改）。

## 说明

本包不含编译产物（`target/`，约 1.5 GB）与运行数据（登录态、缓存）。
`Cargo.lock` 已包含，可复现同样的依赖版本。
